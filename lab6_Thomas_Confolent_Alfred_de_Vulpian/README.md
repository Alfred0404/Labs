# Lab 6 - Containerization and Kubernetes

This folder contains the three Kubernetes labs made with Minikube and Docker driver.

- `lab-1`: Kubernetes basics, service, scaling and rolling update.
- `lab-2`: ConfigMaps, Secrets, environment variables and volumes.
- `lab-3`: Jobs, CronJobs, retries and parallel execution.

Each lab has its manifests and a small README with the observations. All resources were tested in Minikube and deleted after the tests.
